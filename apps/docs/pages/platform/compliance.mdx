# Compliance

wtrdb includes framework controls, live verification, evidence collection/export, reports, policy checks, and one-click framework configuration.

## Typical workflow

1. Select the applicable framework in Compliance settings.
2. Review the control set and current posture summary.
3. Run supported live verification and address failed or incomplete controls.
4. Collect evidence and generate reports for review.
5. Export framework-specific or combined evidence packages when required.

~~~mermaid
flowchart LR
  F[Select framework] --> C[Controls]
  C --> V[Verify]
  V --> E[Collect evidence]
  E --> R[Report and export]
~~~

Compliance features help organize and evaluate evidence; they do not themselves certify compliance. Retain the review and approval process required by your organization and applicable framework.
