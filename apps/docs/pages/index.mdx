# wtrdb documentation

wtrdb is a knowledge-graph platform for turning unstructured information into governed, connected, and queryable knowledge. It is built for teams that need to construct graphs from text, images, video, and live databases, and make them useful in applications and AI agents.

## The platform at a glance

~~~mermaid
flowchart LR
  A[Add source material] --> B[Extract entities and relationships]
  B --> C[Govern and review]
  C --> D[Explore and query graphs]
  D --> F[Publish REST/MCP Brain Endpoint]
~~~

| Capability | What it provides |
| --- | --- |
| Knowledge graphs | Per-knowledge-base graphs, extraction activity, schema discovery, provenance, and 3D exploration. |
| Governance | Evidence, logical, and evolutionary-intent checks in the extraction path. |
| Brain Endpoints | A key-protected REST API and MCP server for one selected graph. |
| Enterprise controls | Authentication, MFA, RBAC, teams, audit records, policies, and compliance evidence. |
