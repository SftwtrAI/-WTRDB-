# Security and screenshot policy

## Documentation security

Never include API keys, endpoint URLs containing real keys, database strings, internal hostnames, private IP addresses, customer graph data, user IDs, tokens, or copied production logs in public documentation.

Use placeholders such as YOUR_HOST, BRN_KEY, and USER:PASSWORD in examples.

## Screenshot capture checklist

Capture only from a disposable demonstration workspace. Before committing an image, verify that it:

- shows no real documents, names, email addresses, or graph content;
- shows no browser extensions, account data, IDs, keys, URLs, or internal service names;
- uses readable, stable UI states;
- has concise descriptive alt text in the page that embeds it;
- is stored under apps/docs/public/images with a descriptive lowercase filename.

Required first-release shots: create/extract a graph, graph explorer, Brain Endpoint publication, RBAC roles/teams, and compliance overview.
